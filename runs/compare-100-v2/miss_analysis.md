# Why the Claude models missed: `compare-100-v2`

Every wrong answer of the API models in this run (20), reviewed by a workflow of Claude Opus 5.5 subagents on 2026-11-06. For each group of misses, one agent recomputed the answer from the digest and diagnosed the misreading. An independent skeptic, without the ground-truth event list, tried to show that the model's answer was defensible or the key wrong. A third agent checked that the diagnosis reproduces the model's exact answer. The models' reasoning is hidden, so each cause is the most likely explanation, with a confidence level. This file is an analysis by agents, not output of the evaluation code.

**Answer keys:** 20 of 20 keys were confirmed correct by two independent agents; no model answer was judged defensible under any reasonable reading, so every miss is a model error.

*Robustness of the review:* one agent of this workflow hit a usage limit and was re-run, and the resume re-ran several other agents live. For three low-confidence misses (H13, H18, H19) the two independent passes preferred different explanations; the final pass is shown, and its text names the alternative. The answer-key and defensibility verdicts were identical in both passes for every miss.
